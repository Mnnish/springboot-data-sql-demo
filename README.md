# springboot-data-sql-demo
A simple Spring Boot project demonstrating how to initialize and populate a database using data.sql. This project shows how to automatically insert data into a PostgreSQL database during application startup using Spring Boot configuration.

🧾 Short Description (for GitHub top line)

👉 Spring Boot demo project for automatic database initialization using data.sql and PostgreSQL

📖 Detailed Description (README style)

This project is a basic example of using Spring Boot with PostgreSQL to demonstrate database initialization using the data.sql file.

It covers:

Automatic table creation using JPA/Hibernate
Data insertion at application startup
Proper configuration of application.properties
Usage of spring.sql.init.mode and spring.jpa.defer-datasource-initialization
🚀 Features
Spring Boot + JPA setup
PostgreSQL database integration
Auto data loading using data.sql
Clean and minimal configuration
🛠️ Tech Stack
Java
Spring Boot
Spring Data JPA
PostgreSQL
Maven
🎯 Purpose

This project is created for learning and demonstrating how Spring Boot handles SQL script execution during application startup.
